# QuickNotes

QuickNotes is a small browser-based note-taking app for creating, organizing, searching, and deleting short notes by category.

## Features

- Add notes with Personal, Work, or Study categories
- Validate empty notes and notes longer than 200 characters
- Search notes without regard to letter case
- Delete individual notes
- Save notes in local storage so they remain after a refresh
- Responsive layout for desktop and mobile screens

## Run locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser, or serve the folder with a local development server.

No build tools or dependencies are required.
